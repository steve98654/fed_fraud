\hypertarget{bottom-line}{%
\section{Bottom line}\label{bottom-line}}

SBA is where the method is proven, so it stays running as the reference
case for every other agency. The next step is to widen it from pandemic
programs to the programs SBA runs every year: 7(a) and 504 loans,
disaster loans and contracting certifications.

\hypertarget{exposure}{%
\section{Exposure}\label{exposure}}

\begin{itemize}
\tightlist
\item
  Shuttered Venue Operators Grant: \$10.1B improper (68.9\%), the
  highest rate of any program. PPP loan forgiveness: 19.2\%. PPP
  guaranty purchases: 13.3\%. (GAO, FY2025)
\item
  Much of the pandemic loss is now recovery work. Live programs carry
  less dollar exposure but are where prevention pays.
\end{itemize}

\hypertarget{public-data-we-can-use}{%
\section{Public data we can use}\label{public-data-we-can-use}}

\begin{itemize}
\tightlist

  PPP and EIDL loan-level data, 7(a) and 504 loan-level FOIA data.
\item
  SAM.gov, FPDS and SBA certification lists (8(a), HUBZone, WOSB,
  VetCert).
\item
  SBA OIG reports and DOJ press releases.
\end{itemize}

\hypertarget{detection-plays}{%
\section{Detection plays}\label{detection-plays}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Shared identifiers and addresses across borrowers (what the current
  SBA work does).
\item
  Certified small businesses acting as pass-throughs for large firms;
  this feeds the DoD and VA briefs.
\item
  Lender and agent concentration: a few lenders or agents behind many
  bad loans.
\end{enumerate}

\hypertarget{what-to-capture-for-other-agencies}{%
\section{What to capture for other
agencies}\label{what-to-capture-for-other-agencies}}

Document the SBA data sources, typologies, methods and measured results
in \texttt{docs/playbook/sba-baseline.md} (plan step 1). Every other
brief assumes that pipeline exists.

\hypertarget{limits}{%
\section{Limits}\label{limits}}

Pandemic program data are fixed in time, and loan-level data omit
personal identifiers.
