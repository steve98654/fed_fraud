# SBA: one-page brief (baseline)

**Priority:** baseline, already underway (score 4.2). **As of:** 2026-10-25.

## Bottom line

SBA is where the method is proven, so it stays running as the reference
case for every other agency. The next step is to widen it from pandemic
programs to the programs SBA runs every year: 7(a) and 504 loans, disaster
loans and contracting certifications.

## Exposure

- Shuttered Venue Operators Grant: $10.1B improper (68.9%), the highest rate
  of any program. PPP loan forgiveness: 19.2%. PPP guaranty purchases: 13.3%.
  (GAO, FY2025)
- Much of the pandemic loss is now recovery work. Live programs carry less
  dollar exposure but are where prevention pays.

## Public data we can use

- PPP and EIDL loan-level data, 7(a) and 504 loan-level FOIA data.
- SAM.gov, FPDS and SBA certification lists (8(a), HUBZone, WOSB, VetCert).
- SBA OIG reports and DOJ press releases.

## Detection plays

1. Shared identifiers and addresses across borrowers (what the current SBA
   work does).
2. Certified small businesses acting as pass-throughs for large firms; this
   feeds the DoD and VA briefs.
3. Lender and agent concentration: a few lenders or agents behind many bad
   loans.

## What to capture for other agencies

Document the SBA data sources, typologies, methods and measured results in
`docs/playbook/sba-baseline.md` (plan step 1). Every other brief assumes that
pipeline exists.

## Limits

Pandemic program data are fixed in time, and loan-level data omit personal
identifiers.
