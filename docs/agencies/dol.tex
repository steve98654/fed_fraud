\hypertarget{bottom-line}{%
\section{Bottom line}\label{bottom-line}}

Unemployment insurance fraud was enormous during the pandemic and is
still the highest-rate program here (14.9\%), but claimant data are held
by states and are not public. With public data we can only point to
states and periods that look wrong. Labor is a strong candidate once a
state or DOL grants data.

\hypertarget{exposure}{%
\section{Exposure}\label{exposure}}

\begin{itemize}
\tightlist
\item
  Federal-State Unemployment Insurance: \$5.6B improper (14.9\%) in
  FY2025. (GAO)
\item
  GAO estimated pandemic UI fraud at \$100B to \$135B.
\end{itemize}

\hypertarget{public-data-we-can-use}{%
\section{Public data we can use}\label{public-data-we-can-use}}

\begin{itemize}
\tightlist
\item
  \textbf{DOL ETA state UI reports:} weekly claims, overpayments, and
  fraud recoveries by state.
\item
  \textbf{DOL grants} on USAspending (state UI integrity grants).
\item
  \textbf{DOL OIG reports} and DOJ releases.
\end{itemize}

\hypertarget{detection-plays}{%
\section{Detection plays}\label{detection-plays}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{State anomalies:} claims that diverge from local job loss, or
  high overpayment rates relative to peers.
\item
  \textbf{Case mining:} extract the schemes from charged cases (shared
  bank accounts, addresses, IP addresses) to build rules states can run.
\end{enumerate}

\hypertarget{first-prototype}{%
\section{First prototype}\label{first-prototype}}

A state-by-state UI integrity dashboard from public aggregates, plus a
playbook of rules drawn from charged cases.

\hypertarget{limits}{%
\section{Limits}\label{limits}}

Detection at the claim level needs state data. This is a proposal-first,
data-later agency.

\hypertarget{who-to-take-it-to}{%
\section{Who to take it to}\label{who-to-take-it-to}}

DOL Employment and Training Administration, DOL OIG, and state workforce
agencies.
