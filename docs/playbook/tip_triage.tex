\hypertarget{bottom-line}{%
\section*{Bottom line}\label{bottom-line}}
\addcontentsline{toc}{section}{Bottom line}

Inspector General hotlines receive hundreds of thousands of contacts a
year, and many of the largest fraud cases started with an insider tip.
The bottleneck is reading: specific, checkable tips sit in the same
queue as vague grievances and duplicates. This extension uses an AI
model to \textbf{order the queue and summarize each tip}, never to close
one. A person still reads every tip; the model changes which ones they
read first.

\begin{itemize}
\tightlist
\item
  \textbf{Two scorers, one output.} A transparent rule-based score is
  the baseline and fallback. A Claude-based score reads the tip for
  program, scheme, specifics, urgency and whistleblower status, and
  returns a structured assessment with reasons.
\item
  \textbf{Safeguards built in:} urgent tips (risk to life, destruction
  of evidence) jump the queue; tipsters who appear to be employees or
  contractors are flagged so whistleblower protections apply; the tip
  text is treated as data, so instructions inside a tip are ignored.
\item
  \textbf{The pilot measures one thing:} how many of the tips that were
  later substantiated would have been in the top 20\% of the queue.
\end{itemize}

\hypertarget{rule-baseline}{%
\section*{3. Rule baseline}\label{rule-baseline}}
\addcontentsline{toc}{section}{3. Rule baseline}

Points for naming a program and a scheme, amounts, dates, addresses,
identifiers (NPI, UEI, contract numbers), an insider account and
mentions of evidence; points off for very short tips and general
grievance language. Crude on purpose: it sets the floor the model must
beat, and its reasons are easy to check.

\hypertarget{model-and-hosting}{%
\section*{4. Model and hosting}\label{model-and-hosting}}
\addcontentsline{toc}{section}{4. Model and hosting}

\begin{itemize}
\tightlist
\item
  \textbf{Model:} Claude (\texttt{claude-opus-5-5} by default) through
  the Anthropic Python SDK, with a JSON-schema output format so every
  answer has the same fields, low effort to keep cost per tip small, and
  server-side refusal fallback enabled.
\item
  \textbf{Hosting:} tips contain personal data about tipsters and
  subjects. The model must run in an environment authorized for that
  data: an OIG's FedRAMP-authorized cloud tenancy (Claude is available
  on government cloud regions of the major providers; check current
  authorization levels) or the agency's own enclave. No tip goes to a
  commercial endpoint without that authorization, and the provider must
  not retain or train on the data.
\item
  \textbf{Cost:} a typical tip is a few hundred words; at low effort the
  cost per tip is a small fraction of a cent to a few cents, far below
  the cost of an analyst's minute.
\end{itemize}

\hypertarget{safeguards}{%
\section*{5. Safeguards}\label{safeguards}}
\addcontentsline{toc}{section}{5. Safeguards}

\begin{itemize}
\tightlist
\item
  \textbf{No automated closure.} The tool orders and summarizes; people
  decide.
\item
  \textbf{Prompt injection:} tip text is wrapped and marked as data; the
  system prompt tells the model to ignore instructions inside it. The
  pilot test set includes tips that try to instruct the model.
\item
  \textbf{Whistleblower protection:} flagged tips are routed under the
  OIG's confidentiality procedures (IG Act, 5 U.S.C. 407(b)); the
  tipster's identity is not shared with the program office.
\item
  \textbf{Bias:} score distributions are compared by language, program
  and region of the tip, and tips written in other languages are
  translated rather than penalized.
\item
  \textbf{Audit trail:} original text, both scores, reasons and model
  version are kept with every tip.
\end{itemize}

\hypertarget{pilot-design-60-days-one-oig}{%
\section*{6. Pilot design (60 days, one
OIG)}\label{pilot-design-60-days-one-oig}}
\addcontentsline{toc}{section}{6. Pilot design (60 days, one OIG)}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Take a closed historical set of 2,000 to 5,000 tips with known
  outcomes (substantiated, referred, closed) inside the OIG's
  environment.
\item
  Score them blind with both scorers.
\item
  Measure recall in the top 20\% and lift over the current order;
  compare model and rules.
\item
  Hand-check 200 model summaries for accuracy and neutrality.
\item
  Pass mark: the model finds at least 1.5 times as many substantiated
  tips in the top 20\% as the current process, with summaries rated
  accurate in at least 95\% of checks.
\end{enumerate}
