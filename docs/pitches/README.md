# One-page pitches: the ten investigations to start first

**Status:** Draft v0.1 (2026-11-01), for Steve's review.
**Builds on:** the [roadmap](../roadmap.md) (idea IDs and the first-ten
list), the [review plan](../review_plan.md) (weeks, data pulls and
validation) and the [agency briefs](../agencies/top33.md) (exposure figures
and sources).

Each pitch is one page, written to hand to the receiving office. It covers
the problem, the public data, the detection method, the program's exposure
from public sources, what we ask the agency for and what it gets back.

Two rules hold for every pitch:

- **Exposure is not savings.** Exposure figures are public program-level
  numbers (GAO improper payment estimates, charged cases, outlays). Improper
  payments include errors as well as fraud. Savings from this work read
  *Pending* until a screen passes validation and a lead package clears
  counsel review.
- **Leads, not accusations.** Public-data results are risk indicators sent
  only to the Inspector General or DOJ component named in the pitch.
